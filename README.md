# DYIDyes
A simple mod that adds craftable hair dyes to Project Zomboid

Tired of putting yourself in danger just to find the perfect hair dye, only to come back with the same common colors? Frustrated that vanilla settings don't let you adjust the spawn rates of hair dyes in your world? This mod gives you another option while still keeping hair dye crafting challenging.

All you need is water, regular paint, and a modifier such as soap, baking soda, bleach, or cleaning fluid. Once you've made a dye, you can mix it with other crafted dyes or vanilla dyes to create new colors using RGB values.

THIS MOD IS FOR B42 ONLY! If you need a B41 version, let me know, and I can try to reorganize the files to make it work.
